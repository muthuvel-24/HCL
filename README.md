# Core Java Checkpoint – OOPS Design

This repository contains simple Java solutions for the 10 questions in Assessment 1.

## Programs

1. Employee Salary Processing
2. Banking Account Management
3. Online Payment Processing
4. Vehicle Rental System
5. Employee Performance Bonus
6. Food Delivery Order
7. Employee Access and Permission System
8. Online Course Fee Calculation
9. Hospital Billing System
10. E-Commerce Product Pricing

## How to run

Each program is a separate Java file with its own public class. Open the required file in an IDE such as VS Code, IntelliJ IDEA, or Eclipse, then run its main method.

The programs use Scanner for normal input. They do not use command-line arguments.

## OOPS concepts

The assessment covers classes, objects, constructors, encapsulation, inheritance, abstract classes, interfaces, method overriding, method overloading, and runtime polymorphism.
